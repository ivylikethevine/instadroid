# instadroid

A real, logged-in Instagram Android app running in [redroid](https://github.com/remote-android/redroid-doc)
(a containerised Android device), driven by `uiautomator2`, publishing the chronological
_Following_ feed as Atom for FreshRSS.

See the [README](https://github.com/ivylikethevine/instadroid#readme) for setup and usage. This
site holds the project's longer-lived reference docs:

- [Roadmap](ROADMAP.md) — planned work, ordered by scope.
- [Version profiles](PROFILES.md) — how per-Instagram-version selector profiles work and how to add one.
- [Run log](RUNLOG.md) — dated device runs behind the profiles: baselines, validations, probes.
- [Compatibility](COMPATIBILITY.md) — which redroid image runs which Instagram build.
- [FreshRSS](FRESHRSS.md) — subscribing, feed auth, OPML, push refresh, running FreshRSS alongside.
- [Operations](OPERATIONS.md) — health, restarts, manual control, alerts, memory, storage and retention.
- [Incidents](INCIDENTS.md) — redroid incidents on the reference host and what was learned from them.
- [OpenAPI spec](openapi.json) — the feed server's routes.
- [Security policy](SECURITY.md) — supported versions and how to report a vulnerability.
- [Contributing](CONTRIBUTING.md) — how to send a bug report or pull request.
- [Code of Conduct](CODE_OF_CONDUCT.md)
